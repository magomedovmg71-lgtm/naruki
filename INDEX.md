# НА РУКИ — демо-сайт кафе

Показательный сайт для клиентов: кофейня и стритфуд, Махачкала.
Заведение вымышленное, заказы и брони не обрабатываются.

Живёт на **magomedov.website/naruki/**, репозиторий `naruki`, ветка `main`.
Выкатка: коммит → `git push origin main`, через 1–2 минуты на сайте.

Локальный просмотр: `node server.js` → http://localhost:8781

## Файлы

| Файл | Что внутри |
|---|---|
| `index.html` | Главная: хиро, популярное, три способа получения, комбо, отзывы, бронь, FAQ |
| `menu.html` | Меню целиком, фильтр по категориям |
| `delivery.html` | Зоны доставки, оплата, путь заказа, самовывоз, FAQ про доставку |
| `contacts.html` | Адрес, SVG-схема проезда, ориентиры, часы, бронь стола |
| `css/style.css` | Вся вёрстка. Переменные и палитра — в `:root` вверху файла |
| `js/menu-data.js` | Позиции меню, категории, зоны доставки. Единственный источник данных |
| `js/main.js` | Корзина, оформление в три шага, бронь, фильтр, анимации, маска телефона |
| `assets/img/` | 28 фотографий в WebP. Имя файла блюда = его `id` в `menu-data.js` |
| `server.js` | Локальный сервер для просмотра |
| `robots.txt`, `sitemap.xml`, `favicon.svg`, `og.jpg` | Служебное |

## Где что править

- **Позиции, цены, зоны** — только `js/menu-data.js`. Меню на главной и на `menu.html` строится оттуда же.
- **Названия секций и тексты** — прямо в HTML, дублируются на четырёх страницах шапка и подвал.
- **Цвета** — 14 переменных в `:root` в начале `css/style.css`. От них считается всё
  остальное: иконки, схема проезда, градиенты заглушек, фон шапки. Смена палитры —
  правка одного блока. Три запасных варианта записаны там же комментарием.
- **Скорость анимаций** — там же: `--slow`, `--mid`, `--ease`.
- **Фото блюда** — положить в `assets/img/<id>.webp`, 760×608. Разметку править
  не нужно: путь строится из `id` позиции. Блок `.ph` остался обёрткой — если
  файла нет, видно цветную заглушку, вёрстка не едет.
- **Карта** — виджет Яндекса, адрес в `data-src` у `#map-live` в `contacts.html`.
- **Домен для canonical, OG и Schema.org** — `magomedov.website/naruki/`, меняется поиском по всем HTML.

## SEO

Свои `title` и `description` на каждой странице, canonical, Open Graph.
Schema.org: `CafeOrCoffeeShop` с адресом, координатами и часами (главная и контакты),
`Menu` с ценами (меню), `FAQPage` (главная и доставка), `BreadcrumbList` на внутренних.
